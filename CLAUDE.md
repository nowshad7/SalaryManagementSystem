# CLAUDE.md

This repository is **PaySQL** — an open-source payroll & salary-management platform built on
Oracle PL/SQL with an ORDS REST API.

For full agent guidance, repository map, and conventions, see **[AGENTS.md](./AGENTS.md)**.
For the plan and roadmap, see **[docs/PROPOSAL.md](./docs/PROPOSAL.md)**.

## Quick rules

- Follow the conventions in `AGENTS.md` (snake_case, correct spelling, money as `NUMBER`,
  dates as `DATE`, compensation as data, typed exceptions, Conventional Commits).
- Do not reuse the legacy `SalaryManagement/` scripts (historical; hardcoded credentials).
- The project is currently in **Phase 0** of the modernization roadmap.
