# Configuration

!!! note "Grows through Phases 1–3"
    PaySQL is configuration-driven. This page will document the configurable pieces.

## What will be configurable

- **Pay components** — earnings and deductions, their formulas and order.
- **Tax / statutory rules** — slabs and contributions, country-aware via config tables.
- **Leave types** — accrual and loss-of-pay behavior.
- **Pay cycles** — monthly, bi-weekly, etc.
- **Connection & secrets** — via environment variables / Oracle Wallet (never committed).
